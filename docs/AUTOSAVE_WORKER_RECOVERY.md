# Request-triggered autosave worker recovery

A failed worker previously disabled worker saving for the entire controller lifetime. That known policy could leave every subsequent autosave on the main thread, even after a temporary problem had ended. The earlier observed8136failure's trigger remains unknown and is not claimed to be diagnosed by this change.

The isolated recovery policy keeps the immediate synchronous fallback and all existing current-game, generation, raw-slot CAS, strict codec, protected-checkpoint and retired-port guards. Only a later ordinary autosave request may create one replacement worker. Failures wait30s,60s,then120s; after three fast replacement attempts, probes continue at most once per300s. There is no retry timer or loop and no permanent exhaustion. Only a valid worker result that actually commits resets the backoff. Preflight acknowledgments, superseded results and measurement resets do not. The existing Performance disclosure shows the current cooldown/slow-probe state and the prior bounded failure cause; no raw errors or save data are exposed.

Thirty focused/existing controller tests passed. The joined native case uses an actual native V16Game and actual strict codec: timeout saves the latest state, a later worker replaces it, a real newer manual checkpoint rejects the older in-flight result, then a fresh result commits. All three storage slots validate, original protected bytes remain exact, restored terrain matches, and late retired-port messages/errors cannot overwrite or poison the new state. A separate frequent-request case proves factory rate bounds across1000+ requests, continued300s probes and eventual recovery without reload. These are save-controller proofs, not an economic campaign run.

Production build passed. The first separate typecheck ended143 with an empty log; its completed rerun exited0. The healthy production preview at owned8140 visibly confirmed3 worker saves/0 fallbacks/0 failures. No safe ordinary browser action for a targeted failure was available, so no browser failure was injected or claimed.
