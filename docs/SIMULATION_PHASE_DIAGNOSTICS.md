# Optional simulation phase attribution

Opening the existing Performance disclosure enables fifteen coarse contiguous Game.step timers. Closing or unmounting it disables them. They attribute step preparation, navigation-grid rebuild, geographic influence, crafting/maintenance, missions/trade planning, construction/ownership, individual decisions/work, movement/combat, wildlife/communities, routes/farms/yields, society/survival, vision/encounters, rival strategy, final reconciliation and visual effects.

The optional second argument to Game.step is a diagnostics-only profiler. Its disabled path reads no clock. It does not replace height, water, travel, navigation or AI methods; thus it preserves the terrain-cache method identity guard. It does not write GameState, consume randomness, change workload cadence or serialize timing. A finally block closes the current sample on exceptional exits. Each phase keeps at most 240 samples. Resetting the existing measurements also clears these phase samples without changing enablement.

Rows are coarse processor elapsed time, per occurrence of that phase. Conditional or paused steps may have different sample counts. Phase p95s need not sum to the overall p95. The probe adds clock-read and bounded sample-accounting overhead while enabled, and this diagnostic cost must be disclosed when interpreting a capture. It is not GPU timing or an FPS improvement.

Validation ran four cases with zero skips: existing RuntimeProfile attribution; bounded/disabled/reset clocks; native V18 opening with 90 actual steps in each of five absent/disabled/enabled runs; and the declared authored native V18 100/60 fixture with 180 actual steps in each of five runs. All full serialized snapshots at every 30 steps, final state, external RNG state and draw count were exactly equal across each group. Actual simulation time advanced and no simulation errors occurred. This is bounded parity evidence, not a universal replay guarantee. The optional 100/60 case explicitly skips if its public owned fixture has not first been generated; it was present and executed for this qualification.
