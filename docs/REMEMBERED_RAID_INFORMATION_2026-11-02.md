## Behavior

A society's raid utility uses its physically returned dated structure report, including only locally visible defender and fortification estimates recorded at observation. Historically mapped ground cannot reveal a later paid warehouse, and a private live remote treasury, new structure, changed health or newly moved army is not substituted for the report. Known partner selection uses recorded settlement/structure provenance instead of current global foreign supply drops and private alive flags.

Departing units receive a saved targetSite coordinate/dimension commitment and no live remote target pointer. The inert planning object is never used as a damageable structure. A party travels to its remembered location, binds the actual structure only when within 26 metres, and discovers destruction or absence locally. Offscreen target death or a remote society alive flag no longer cancels the expedition. Real loaded loot, local target outcome, actual treaty or journey deadline can still cause physical withdrawal. Nearby ordinary combat remains available during approach.

Legacy active missions without targetSite recover their destination from an existing actor's serialized attackDestination, which is actual paid-order provenance. They do not synthesize a live unknown replacement coordinate. If no historical order endpoint remains, they safely return the same residents rather than invent a target. The optional saved coordinate/dimension field is bounded and validated; existing inventory/pack/actor ownership executors remain intact.
