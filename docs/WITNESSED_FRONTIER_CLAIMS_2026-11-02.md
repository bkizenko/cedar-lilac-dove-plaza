# Witnessed frontier claims — focused repair candidate, 2026-11-02

Baseline: `920952a`, isolated in `.play/witnessed-claims-review`. Source-only patch: `.play/witnessed-claims.patch`. No shared source was overwritten or staged by this agent. This repairs one demonstrated information leak; **M2-07 remains pending**, because a separate unobserved second-town leak is reproduced below.

## Corrected behavior

Old terrain survey is no longer evidence of a subsequently built player frontier post. An actual living, unconfined NPC person within 26 metres can establish a dated fact about the completed post. A society retains that last known position and appraisal after its observer leaves. Current remote movement, destruction, new posts, or resource changes cannot silently modify the fact. Physically revisiting the old location can discover removal; visiting a current post can refresh its fact. Player firsthand meetings and live local observations remain valid and unchanged.

New state is `GameState.observedClaims`, optional for old saves. Each fact contains version, observer society, owner, post ID, last seen position/time, physical witness ID, active flag and bounded local appraisal (value/woodland/minerals). It contains no current stockpile. The two-second review and 512-fact cap are adjustable in `CLAIM_OBSERVATION_RULES`. At capacity, the oldest inactive fact is forgotten first, otherwise the oldest active fact. Historical witness or post entities may cease to exist without invalidating memory. Strict decoding rejects extra keys, duplicate observer/post pairs, invalid societies/IDs/coordinates, future timestamps, malformed flags and out-of-range appraisal values. Legacy saves without facts remain accepted.

Patch fields are deliberately narrow: `frontiers.ts` owns observation/pressure and exports the validator/type; `types.ts` adds only `observedClaims`; `persistence.ts` adds the validator import and one separate validation call. Existing military territorial strength, guard allocation, and pressure coefficients stay unchanged. There is no report-delivery mechanism added for frontier posts; present firsthand observation is the implemented source. The existing separate market-report route still requires actual physical NPC return.

After another strict save, the observer walks back to the remembered site and discovers absence. The moved structure does not reveal its new location. Total observer travel is 272.76 metres. Separate cases cover unseen destruction/replacement identity and a dead body that cannot witness.
