# Observed port reports: isolated follow-up

This delta applies after the delivered-diplomacy candidate based on 79d6148. It does not replace that stable patch and does not qualify M2-07 overall.

The coastal landing chooser no longer turns historical empty terrain into knowledge of a later paid foreign dock. It uses dated structure facts. A living NPC observes structures within 26 metres, carries bounded reports on its own body and only publishes them when it reaches a real own supply entrance. Player firsthand sight can publish immediately. A dead or captive observer cannot publish; historical observer ownership remains valid through capture. Own fortifications do not create a new automatic remote report channel in this patch.

New optional saved fields: GameState.structureReports and Unit.structureReportCargo. Facts contain a dated structure identity, owner, location, dimensions, health and local visible defense estimate. Inactive facts record actually revisited absence. Shared capacity is 1024 facts, carried capacity 64 per body; oldest dated facts are evicted. A two-second review uses spatial buckets for current structures, people and shared remembered locations. It does not scan every shared memory per person. Validators reject unknown keys, invalid IDs/types/times/coordinates/counts and duplicate memories; old saves with absent fields remain accepted. Existing paid voyages keep their serialized destinations, cargo and accounting.

Evidence: 18/18 combined new causal, existing coastal and delivered-diplomacy cases passed, typecheck passed and development build passed. Logs: /tmp/observed-infrastructure-final-tests.log, /tmp/observed-infrastructure-final-type.log, /tmp/observed-infrastructure-final-build.log. New files were then formatted and the focused causal test rerun. Metric: docs/metrics/observed-port-report-2026-11-02.json.

The connected controlled scenario pays 40 logs, walks the actual builder 52.260 metres to complete an unseen dock, walks a real opposing observer to see it, saves while its report is still abroad, restores the declared controlled terrain and walks the same observer to its actual supply entrance. Only physical arrival publishes the fact. A supplemental offscreen coordinate mutation verifies dated location persistence; physically revisiting absence and returning updates home knowledge. The absence check is not claimed as a paid physical destruction scenario. No midrun resource grants or forced job completion occur.

Four existing coastal fixture cases required explicit initial dated structure reports because their authored prior knowledge previously only mapped terrain using a setup scout reposition. The helper endowStructureReports is test-only declared initial knowledge; it is not called by runtime and must not be used midscenario. Existing paid hull, voyage and return tests pass with their intended initial observed ports declared honestly.
