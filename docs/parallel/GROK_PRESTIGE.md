# Grok: prestige and awareness

Read COORDINATION.md, the master plan's territory/score section, existing settlement/migration, leader dialogue, society relations and observed-intelligence modules. Work only on agents/grok-prestige from latest origin/main. Codex owns current food/goat/site/identity/sailing integration; avoid those implementations.

## First complete vertical slice

Add a versioned tunable prestige model with visible breakdown: sustained healthy population, useful controlled land and finite resources, food security in population-days, demonstrated useful practices, completed real trade, actual defended/achieved war aims and maintained civic art/monuments/wonders. Distinguish snapshot wealth from earned historical achievements; no infinite points for repeated flags, circular trades, spoiling stock or repeatedly slaughtering spawned enemies. Never equate seed/chaff counts with edible meals. Existing unimplemented wonders must not generate score merely because a menu mentions them.

Keep prestige separate from awareness. A society only learns achievements from actual observed contact, returning traders/envoys/visitors or another informed society sharing a report. Record dated source/confidence/expiry and bounded propagation. No global discovery of private stocks, settlements or scores. Unknown rivals stay unknown in the player's comparison view.

Use perceived prestige plus actual housing/food/safety/route/difficulty incentives for migration, delegation interest and raider attention. Do not make score a universal productivity multiplier. Morale, training, useful institutions and specialization can have explicit measured effects where implemented. A flag records a claim; control still needs actual occupation/supply/reach/opposition. Contested flags must not silently transfer ownership.

Expose concise ledger tabs/breakdown and meaningful in-world feedback, not a dashboard covering the map. Use existing real society contacts and event actors, not invented offscreen delegations or teleported awards. Keep stage1 bounded if an actual physical delegation adapter is absent; report that gap rather than fabricate it.

## Required evidence

Measured score changes only from actual state/events, stability/limits and no replay farming; unaware society has no knowledge; real contact/report transfers information once and it decays; actual migration/raid-interest inputs change only where awareness exists. Strict old/new save handling, full/partial community transfers and bounded history. Tests of helpers alone do not qualify visible complete behavior; include short executed scenario and actual UI/controller behavior, then report remaining limits. Do not change the frozen98-gate denominator.

## Retained scope

Original generated culture wonders with physical staged construction/prestige; useful territory/fort/port objectives and sustained contested-area control; independent society diplomacy/alliance/war/conquest/tribute/puppet choices. No instant annexation or arbitrary tech tree; later eras deferred. Do not reverse-engineer proprietary Civ/Dawn of Man code or import their protected assets; learn from public screenshots and properly licensed references.
