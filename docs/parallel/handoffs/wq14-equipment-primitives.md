# WQ-14 equipment primitives — adapter handoff

Source primitives only; carried armor/weapons/tools/animals must remain **unselectable in tradeNeeds until Claude supplies ID/holder-based escrow, receipts, interruption and save tests**. Do not re-enable scalar `items.paddedArmor` or remove live livestock into an escrow array.

Armor (`work/wq14-armor-2026-11-11`, `ce4fd9a`): `moveArmorAsset(g,armorId,nextHolder,targetTeam?) -> {accepted,reason}` supports actual cache, ground, worn `unit`, and nonprotective `carried` custody. `Unit.armorCargoId` is the reciprocal pointer to a single carried asset; condition, ID, project provenance and creation time stay unchanged. Foreign building cache ownership is derived; foreign camp ownership is explicit. Transfers check actual body/cache/ground reach and cache capacity. Cargo grants no armor protection. `armorCarriedUnits(g,unitId)` exposes load units. Root owns shared burden/task-registry integration.

Weapons (`weaponCargo.ts`): `loadWeaponCargo(g,unitId,kind,amount,sourceTeam?,cacheId?)`, `deliverWeaponCargo(g,unitId,kind,amount,targetTeam?,cacheId?)`, and `pickupWeaponCargo(g,unitId,bundleId,kind,amount)` return `{accepted,reason}`. Kinds are plural native stock keys `spears|bows|blades`. `Unit.weaponCargo` is a finite count bundle, distinct from armed unit type/stats. Successful physical loads debit existing tribe stock once; delivery debits the body once. `weaponCargoLoad(u)` and `WEAPON_CARGO_LOAD_UNITS` expose weights. Caller authorizes the commercial/capture transition; the primitive does not price, consent, reserve or issue receipts.

Root integration required: call `reconcileWeaponCargo(g)` before dead-unit removal and before owner snapshot encoding; retain a dead unit while `weaponCargo` remains (ground saturation keeps custody rather than deleting goods). Register `validWeaponCargoState(s)` in strict saves and `weaponCargo` as a task commitment. Ground bundles live in optional `state.droppedWeaponCargo`; capture keeps the existing bundle on the actual body without arming it. The primitive's 40-unit weapon bound supplements, and does not replace, root's total mixed-cargo capacity/admission checks.

Five armor and four weapon controlled guard tests are prepared on their branches. Armor's initial five were reported passing by root; marker and weapon integration qualification belongs to root's combined source. These fixtures do not prove native journeys, full trade activation or publication.
