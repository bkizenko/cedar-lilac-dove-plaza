## What changed

The seed selects flatter/rolling/hilly/mountainous character with adjustable22/30/28/20 weights. Smooth regional variation modifies the actual ground, not only a label. Five geological district bundles distribute required families across substantial landmasses, with ordinary terrain between and real connected lake/outlet/fall/downstream drainage. A mountainous map has no universal minimum gentle-land quota. Safe founders, actual freshwater, buildable foundations, above-average scenic location, dry roots and usable routes still matter.

The C3 straight wall was a real generation artifact: a full-depth repair cut stopped abruptly at a protected feature boundary, and a failed legacy repair could leave its partial terrain behind. C4 rolls back failed legacy changes and caps new cut depth continuously by actual protected/camp/world-boundary clearance. Actual preserved rare cliffs are not globally blurred. The watershed connects downhill to independently existing river water or boundary-connected ocean; no synthetic isolated water or reduced biome quota substitutes for physical coverage.

C4b searches bounded alternate outlets within one world rather than repeatedly regenerating a whole mountainous world. Both original counterexamples now use native attempt0. The ecology override retains the larger original required connected region area after real channels remove dry land. The curve preflight, added-edge cap, descending wet-course checks and eight actual connected region quotas remain enforced.

An exact AABB polyline query preserves original segment order/ties/arithmetic; V18 skips discarded older noise. Six entire generated worlds match the pre-optimization C4b control byte for byte. This is an equality result, not an FPS claim.

## Still required / limits

Independent current C4b five full native cases and twenty fixed/held-out cases, plus actual root desktop gallery, are separate acceptance work. This package grants no release-gate credit itself. C4a desktop review removed the giant wall, but its imagery does not substitute for C4b review because current homes/outlet selection can differ. The visible staircase riverbank issue remains pending V19 sparse shared-physics/render refinement. No claim that distribution alone smooths riverbank meshes. Local shoreline, rare feature and whole-map appearance still require perceptual review.

The first paused test incorrectly asserted every saved metadata field remains identical after a zero-time update. Initial influence/cosmetic reconciliation can legitimately change metadata. That failed assertion is recorded; the corrected test checks actual time, world, people and stock, plus exact strict reload. No runtime source was changed to force the test green.
