The frozen atomic-handover owner packet is supplemented by two controlled journey cases. These use declared authored terrain and initial societies, ordinary paid commands and physical Game.step travel; they do not establish native-map voyage frequency or autonomous fleet commissioning after conquest.

## Coastal refusal regression

An actual 40-log/4-stone hull finishes; the captain loads 12 existing logs and finite food/water, sails to the observed village and physically receives a refusal because the declared partner has no requested stone. After the exchange, atomic community handover retains the same actor/hull position, cargo, provisions and talk history. Immediate strict save passes. Before the correction, physical return delivered logs but inserted a rival planner refusal owned by player0; the next strict save failed. The correction retains the original voyage society as historical refusal owner. NPC planner refusals require two distinct NPC societies; player-partner/self records are not invented. The original dated carried trade report still reaches the actual new community.

The new regression and six existing coastal trade/commission cases pass 7/7 (`/tmp/annexation-coastal-return-fixed.log`). Typecheck passes (`/tmp/annexation-coastal-types.log`). Source increment is separate from the frozen38-file owner export.

## Authority messenger

The same body reaches an owned cache, clears its mission and returns its remaining finite provisions; strict save passes before and after return. This one controlled case passes (`/tmp/annexation-message-return.log`). No runtime change was required for this case.
