# Language audit: era-true wording

**BLUF.** The game talks like an NGO in a hide tent. A first meeting greeted the owner with "Community representative", "Discuss an agreement" and "Where do we stand?". Fixed for every first-meeting and conversation string, the banner/notification chokepoint, trader verbs and the Force/Leave labels, through one pure vocabulary layer (`src/game/vocab.ts`) keyed by age (band, early farming village, chiefdom, early state, kingdom) and by culture style (river, upland, coast, steppe, forest, desert, island). A switch (`setEraVoice(false)`, or `localStorage hearthwild.voice=modern`) restores the old wording byte for byte. **291 player-facing strings across 74 files still use modern or bureaucratic words**; 197 are hard misses (listed with a replacement below), 94 are soft (words that need a per-age choice, not a blanket swap). The banner path already rewrites most of them at run time (`eraText`); the rest are static UI text that needs a hand edit as each panel is next touched.

## Rules of the voice

- Short, plain, hard. Nouns you can hold: band, hearth, clan, stores, goods, kin, pack, fire. No profanity, no cute, no office words.
- Titles by kind: band Headman / Eldest / Speaker / Hunter; village Headman / Elder of the hearth / Kinsman; chiefdom Chief / War-chief / Herald / Spearman; early state Priest-king / Lord of the city / Herald; kingdom King / High king / Man-at-arms. Never representative, delegate, minister, ambassador, official.
- Culture flavour is original: river-kin, hill-kin, shore-kin, herd-kin, wood-kin, well-kin, sea-kin, plus a greeting pair and an oath each ("by the low water", "by the horse-skull"). No real people's exact terms.
- "Treaty" is allowed again from age 3 (early state: oath, embassy); never before.
