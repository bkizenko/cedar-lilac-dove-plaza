# Practical cultivation before permanent buildings

A household without buildings can now conduct its existing crop experiment at its actual communal camp cache. `cropTrialWorkplace` selects the primary completed town hall when one exists, otherwise `campAnchor`; it does not create a building, fireplace or inventory. Admission checks a real route before spending the existing four crop samples. Assigned adults physically walk to a reachable camp approach, and only present workers advance the trial. A newly blocked route holds the paid trial with an explicit reason and no remote progress.

The existing cooperative cap and diminishing contributions remain unchanged. A saved trial retains its progress, participants, paid samples and relocated `campSites` identity. Direct orders interrupt only the ordered participant. Auto work remains opt-in and does not take residents with explicit work locks. Completion grants cultivation once and returns manual workers to hold. No sample, food, log, stone, seed basket or architecture is granted by the experiment.

The first-sample notification and cultivation blocker now describe the actual manual Test seeds action or opt-in Auto work rather than promising automatic research. The Knowledge proposal and actual `runKnowledgeAction` command now use the same real workplace and route checks. Held uncommitted adults can take a manual trial or Find crop samples order while Auto work is off; active locked gatherers, water carriers and paid workers remain protected. Active trials can add distinct experimenters up to the existing cap of three. The read-only topic reports participant count and names the actual camp patch. Root integration also updates the read-only farming-progress summary and SettlementLedger copy to remove the false building prerequisite and use planting/ground-preparation language.
